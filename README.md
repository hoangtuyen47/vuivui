## 🛠️ HƯỚNG DẪN QUẢN TRỊ & ĐỔI MẬT KHẨU ADMIN

1. Trên website, Thầy bấm nút **"Bảng Quản Trị: Thêm Công Cụ & Lớp Học"** ở cuối cột bên trái (hoặc chữ "Khu vực Quản trị" ở chân trang).
2. Nhập mã PIN Quản Trị: Mặc định là **`admin123`** (hoặc mật khẩu mới nếu Thầy đã đổi).
3. Các chức năng trong Bảng Quản Trị:
   - **+ Thêm Công Cụ**: Nhập tên, ảnh, tính năng gạch đầu dòng, link trải nghiệm, link đăng ký.
   - **+ Thêm Lớp Học**: Nhập tên khóa, đối tượng, lịch học, link đăng ký.
   - **+ Thêm Học Liệu**: Nhập tên dự án, ảnh, mô tả, mã nguồn, sơ đồ.
   - **🔒 Đổi Mật Khẩu Admin**: Nhập mật khẩu hiện tại và mật khẩu mới để đổi mã PIN bảo mật cho hệ thống.
4. Bấm nút **"Lưu & Hiển thị thử"** hoặc **"Lưu & Cập Nhật Mật Khẩu Admin"**.
5. Thầy bấm nút màu xanh **"📥 Xuất file data.js Cập Nhật"**: Trình duyệt sẽ tải về file `data.js` chứa toàn bộ công cụ, lớp học và cả mật khẩu mới đã đổi. Thầy chỉ cần kéo file `data.js` này thả vào GitHub repository `hoangtuyen47/vuivui` là dữ liệu và mật khẩu mới sẽ có hiệu lực vĩnh viễn trên mọi thiết bị!
